# R2: confresolve

Feature directory: `specs/004-r2-confresolve` · Tests: py

## /speckit-specify

```text
Feature directory: specs/004-r2-confresolve
Parent roadmap: specs/pipelines/ROADMAP.md → entry R2. Design: specs/pipelines/design-v7.md (§0 confresolve/identity keys, §4.0 rule 2, §4.4, D-5, D-7, D-26) and design-v7-appendix-a.md §A.1.

Make confresolve the only way to obtain a validated pipeline configuration.

Why: configuration has to be assembled reproducibly from layers, both for a confdir and later for a rootdir, and nothing else should construct a PipelineConfig.

Requirements:
- confresolve(directory, overrides) takes a confdir or a rootdir's conf set and returns one validated PipelineConfig. It has no side effects and no cache; every call re-resolves.
- Layers, lowest to highest: kind defaults → includes → conf.toml → overrides → {var} substitution → validation.
- kind: accepted top-level key, default "generic". The generic kind contributes no defaults. The layer exists so R5 can plug real kinds into it.
- includes: accepted top-level key, a list of paths relative to the confdir, merged in order before conf.toml. Absolute paths, paths escaping the directory (..) and missing files raise ConfigError.
- overrides: dotted keys → values, applied after conf.toml. An override of an identity key (long_name, name, loop_number) raises ConfigError.
- Substitution: any key may reference any other key. Values inside table arrays ([[dataloads]], later [[hooks]]) are not substituted and cannot be referenced; they pass through untouched.
- Every former config entry point (load_pipeline_config) goes through confresolve or is removed.

Out of scope: replaying overrides recorded in provenance (R3b); real kinds (R5); a resolve cache.

Success criteria: the suite is green; pure-Python tests cover layer precedence, includes (order, refusal of absolute paths and ..), identity-key refusal, substitution across layers, and the table-array pass-through.
```

## /speckit-plan

```text
Python ≥3.11, tomli, pydantic 2; no new dependencies. New module milk/confresolve.py (or milk/config/resolve.py; choose one and use it everywhere). It reuses the existing substitution engine in infra/toml_manipulation.py, extended only as needed.
Merging is a recursive dict merge where the later layer wins on leaf keys. Table arrays are replaced whole, never merged element-wise.
The kind-defaults layer is a function seam (kind id → defaults dict) returning {} for "generic"; R5 replaces its body.
Errors: ConfigError with context (file, key, layer).
Tests: py only (tmp_path confdirs).
```
