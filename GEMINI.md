# Project: milk

## General Instructions for coders

- When generating new code, please follow style and standards from module `milk_example_module`
- FPS-enabled functions should follow template in `milk_example_module/examplefunc2_FPS.c`
- Stream processing functions should follow template in `milk_example_module/examplefunc4_streamprocess.c`
- When generating new code, prioritize runtime performance
