# Project: milk

## General Instructions for coders

- **CRITICAL BRANCHING RULE**: DO NOT modify or push to the `dev` branch. All new work MUST go to `framework-dev` or a feature branch derived from it. This rule strictly applies to `milk`, `cacao`, and `ImageStreamIO`.
- When generating new code, please follow style and standards from module `milk_example_module`
- FPS-enabled functions should follow template in `milk_example_module/examplefunc2_FPS.c`
- New V2 compute units (standalone + CLI) should follow template in `milk_example_module/examplefunc_fps_cli_poc.c`
- Stream processing functions should follow template in `milk_example_module/examplefunc4_streamprocess.c`
- When generating new code, prioritize runtime performance (see `.agents/rules/performance-practices.md`)
- For full onboarding, read `AGENTS.md` and follow its reading order
