# Module: kdtree

K-dimensional tree (kd-tree) data structure for efficient
nearest-neighbor and range queries in multi-dimensional
spaces.

Based on the kd-tree library by John Tsiombikas (BSD
license).

## Source Files

| File | Description |
|------|-------------|
| `kdtree.c` | Kd-tree construction, insertion, nearest-neighbor search, and range queries |

## Dependencies

- `CLIcore` (includes transitive: `milkfps`, `ImageStreamIO`, `milkdata`)
