# isio-tools

ImageStreamIO command-line utilities.

## Executables

| Command            | Description                                        |
| ------------------ | -------------------------------------------------- |
| `isio-stream-info` | Display detailed info about a shared memory stream |

## Dependencies

- `ImageStreamIO` — Shared memory access

## Notes

These are lightweight standalone tools that directly use the
ImageStreamIO library without requiring the full milk framework.
